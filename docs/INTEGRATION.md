# care → stories 연동 제안 (care 파일 수정 없음)

> 이 문서는 **제안만** 합니다. care 의 어떤 HTML/CSS/JS/Functions 도 이번 작업에서 수정하지 않습니다.
> 아래는 care FREEZE 가 해제될 때 적용할 수 있는 동선 옵션입니다.

## 원칙
- 연동은 **단방향·읽기 전용 링크**로 충분합니다. (데이터 연결 불필요)
- 문진/대시보드에 갤러리 링크를 거는 것은 **care HTML 1줄 추가** 작업이며, FREEZE 기간에는 보류합니다.

## 옵션 A — 문진 완료 화면에 갤러리 링크 (가장 가벼움)
care 의 문진 완료 화면 하단에 다음과 같은 외부 링크 한 줄을 추가하는 것을 제안합니다(추가 시점은 FREEZE 해제 후):
```
다른 분들의 여정이 궁금하다면 → 하루센스 스토리 갤러리
https://stories.harusense.com/stories/
```
- 새 탭(`target="_blank" rel="noopener"`)으로 열어 care 세션과 분리.
- 데이터·토큰 전달 없음. 순수 정적 링크.

## 옵션 B — care 푸터/메뉴에 상시 링크
- care 공통 푸터에 "스토리 갤러리" 텍스트 링크만 추가.
- 역시 정적 링크 1줄. care 로직 변화 없음.

## 옵션 C — QR / 카카오 채널 (코드 변경 0)
- 갤러리 URL QR을 진료실 인쇄물·카카오 채널에 노출.
- care 코드 변경이 전혀 필요 없어 **FREEZE 중에도 즉시 가능**.

## 금지 사항 재확인
- care → stories 로 환자 식별자/문진 원문 전달 금지.
- stories 가 care-db 를 조회하는 자동 동기화 금지(=FREEZE 위반).
- 큐레이션은 항상 사람이 익명화·확정한 narrative 만 갤러리에 게시.
